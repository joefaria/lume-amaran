# Apoie o Lume com R$ 5

[← Voltar ao Lume](../README.md)

O Lume é gratuito e de código aberto. Se o app facilitou o seu trabalho, uma contribuição de **R$ 5 via Pix** ajuda a manter o projeto em movimento. Contribuir é opcional; todos os recursos continuam disponíveis para todo mundo.

  <img src="support/pix-5-reais.jpg" alt="QR Code Pix para uma contribuição de cinco reais ao criador do Lume" width="300">

1. Abra o aplicativo do seu banco e escolha **Pix → Ler QR Code**.
2. Escaneie a imagem acima. Se estiver no mesmo dispositivo, use o código copia e cola abaixo ou a opção de ler uma imagem da galeria do seu banco.
3. Confira **R$ 5,00** e o recebedor **Jonatas Soares de Faria** antes de confirmar.
