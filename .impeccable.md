## Design Context

### Users

Mac users adjusting their own amaran studio light while working or recording. The creator's original use case is quick power, brightness and temperature control from the menu bar, without a phone or Sidus Link. Model support expands through community requests and hardware validation.

### Brand Personality

Precise, calm, futuristic. The user explicitly requested an Apple-like interface following HIG, a NASA-inspired futuristic icon, Phosphor icons, and both dark and light appearance.

### Aesthetic Direction

Compact native macOS spaceflight control panel, with the restraint of Control Center. The creator supplied references with dark instrumentation, amber accents, scales and Apple glass. SF system typography, semantic macOS colors, native sliders, Phosphor glyphs and an original glass orbital light-beam app icon. Native Liquid Glass on macOS 26+ and material fallback on older systems. Appearance follows macOS, as HIG recommends. The menu bar icon is a separate minimal monochrome template. Avoid decorative charts, fake telemetry and unnecessary controls.

### Design Principles

1. The main panel exposes the selected fixture, emitter power, brightness and white temperature. Secondary actions live in a menu/settings.
2. Use native behaviors, accessibility labels, keyboard focus, scalable text and semantic contrast. Never remove status/error feedback for visual minimalism.
3. Controls remain disabled until an authenticated state is received; startup never applies old light settings.
4. Avoid redundant status messages, marketing text, oversized icons, repeated cards and persistent preset tiles. Preserve quick presets through progressive disclosure.
5. Follow Apple HIG where applicable; the explicit native-system and Phosphor requests override web-font and illustration conventions in general design skills.
